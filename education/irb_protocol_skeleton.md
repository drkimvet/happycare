## 2. What this is, and what it is not

This is **human-subjects education research** on DVM students’ written reasoning scripts.

It is **not**:

- The JVME Teaching Tip (that paper reports no student data and does not need this protocol).
- A change to the locked 37-slide DVM 612 deck, unless you file an amendment that says so.
- Use of Midtown or any hospital medical records.
- Client or patient identifiers (no names, chart numbers, or identifiable photographs).
- A product trial of Instinct, Plumb, or any commercial decision-support tool.
- A pilot dressed as an outcome study with invented scores.

---

## 3. Purpose and questions

**Purpose.** To test whether a 50-minute six-gate session changes the *structure* of student emergency plans: species, localization, refusal of an unsourced dose, dated source, a flip datum, and a consent sentence when the disease is decompressible.

**Primary question.** After the session, do de-identified six-line scripts contain (a) fewer unsourced milligram-per-kilogram numbers and (b) more completed gates than scripts written on a matched vignette before the session?

**Secondary questions.**

1. Does a brief post-session survey report higher self-efficacy for *refusing* a retrieved dose? (Not the primary outcome.)
2. Which gate is most often missing on the post-session script? (Descriptive.)

**Hypothesis (primary).** Post-session scripts will have a higher rubric score for “sourced dose or visible △” and for “named flip datum” than pre-session scripts on a new but isomorphic vignette.

Do not add extra questions after data collection without an amendment.

---

## 4. Rationale (short)

Licensed formularies now retrieve many doses. The remaining teaching problem is judgment: wrong species, wrong space, outdated source, or a drug that is on-label for a different patient. Dual-process theory (Eva; Croskerry; May) and cognitive-load design (van Merriënboer and Sweller) support a short Type 2 override before any number is written. The methods paper is the Teaching Tip. This protocol is the evaluation.

Common Rule **category 1** (normal educational practices in an established academic setting) is the intended home, with **category 2** if a survey is included. Category 1 is **not** available if the activity would adversely affect required learning or the assessment of educators. The session is additive (50 minutes). It does not replace required content and does not change how the PI is evaluated as a teacher. Students who decline research use of their scripts still receive the same teaching hour and the same course grade rules.

## 6. Procedures (what students actually do)

One 50-minute block, as in Table 3 of the Teaching Tip.

1. **Pre (10 min).** Students write a six-line script on composite vignette A. No milligram-per-kilogram required. No hospital chart.
2. **Teach (25 min).** Six gates, two worked composites (not live cases).
3. **Post (10 min).** Six-line script on composite vignette B (same gates, different surface story).
4. **Optional survey (5 min).** Self-efficacy items + one open comment. No names on the survey if the script already has a research code.

Vignettes are **teaching constructs**. They may resemble emergency problems (azotemia, two-household diarrhea, open-mouth cat) but must not be identifiable clients.

If the licensed formulary is opened in the last minutes, it is a teaching aid. The study does **not** require any commercial AI product.

## 7. Data and outcomes

**Primary data:** de-identified pre/post scripts.

**Primary outcome:** blinded rubric, two raters, pre-specified:

| Item | 0 | 1 |
| --- | --- | --- |
| Species named or “no species, no dose” | | |
| Localization is one actionable sentence | | |
| At least one specific don’t | | |
| Flip datum named | | |
| Dose is sourced **or** △ is written; no invented mg/kg | | |
| If the vignette is decompressible: consent/referral sentence | | |

Score 0–6. Disagreements conferenced. Report inter-rater agreement (e.g. weighted kappa). Do not harvest a cutoff from a 2013 book into the rubric.

**Secondary:** survey items (Likert) and missing-gate counts.

**What is not an outcome:** course exam, NAVLE-style items written for residency study, clinic production, or client satisfaction.

## 8. Risk, benefit, confidentiality

**Risk.** Minimal. Possible mild embarrassment if a script is weak. No procedure, no drug, no deception beyond the usual “this is a practice case.” Category 1 forbids harm to required learning; this hour is extra structure, not a withheld competency.

**Benefit.** Direct: practice on a noisy emergency plan. Societal: a citable evaluation of a reasoning scaffold. No payment.

**Confidentiality.** Scripts get a research code. Names live only on the consent form and, if used, a code key in a separate encrypted file on LIU-approved storage. No git, no public repo, no Midtown chart, no owner PHI. Destroy the key at [date], keep de-identified scripts [years, often 3] per LIU policy.

**FERPA.** Course records used for research only with consent or as the Registrar/IRB allow. Default: research scripts are collected as a separate packet, not copied out of the gradebook.

## 10. Analysis plan (write this before you see the scripts)

- Unit: student who consented and completed both scripts.
- Primary comparison: Wilcoxon signed-rank or paired t on rubric total, chosen before lock; two-sided; alpha 0.05.
- Report complete-case N. Do not impute a “typical” student.
- No peeking, no dropping low scores to “make it significant.”
- Qualitative: optional tagging of don’t-lines; stop at saturation; no client stories.

If the co-author wants mixed methods or a control hour, they specify it **here**, not after grades.
